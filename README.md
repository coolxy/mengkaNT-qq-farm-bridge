QQ农场助手桥接 v1.3.1
=====================

作用：把萌卡在线 QQ 的农场登录 code 自动/手动推送到 QQ农场智能助手（qq-farm-bot）。
支持多台农场服务器：插件管理页可新增 / 删除 / 选择推送目标，推送只发到选中的那台。
自带上游 Node 运行时，Windows / Linux 都不需要系统装 Node.js。

本版本提供两个平台的包（内容相同，仅入口可执行文件不同）：

  Windows x64 萌卡  ：mengkaNT-qq-farm-bridge-1.3.1-win-x64.zip       入口 bin/node-win-x64.exe
  Linux x86_64 萌卡 ：mengkaNT-qq-farm-bridge-1.3.1-linux-amd64.zip   入口 bin/node-linux-amd64

装错平台会启动失败（Windows 不能执行 Linux 二进制，反之亦然）。

安装（萌卡插件）
----------------
1. 萌卡 WebUI →「插件服务 / 插件导入」→ 上传对应平台的 .zip（或 .tar.gz）；
2. 勾选「来源可信」后确认；若提示权限变更，再确认一次即可；
3. 插件卡片「配置」里填第 1 台农场：
     主服务器地址      http://127.0.0.1:3007
     管理员用户名      admin（「访问 Code」版可留空）
     密码 / 访问 Code  账号密码版填管理员密码；「访问 Code」版直接填访问 Code
4. 启动插件卡片，首次启动会自动推送一轮（日志在插件卡片「日志」里）。

多台农场
--------
1. 点卡片「管理后台」打开插件页面（Windows 上同样由萌卡网关代理，不用直接访问端口）；
2. 「服务器管理」里点「＋ 新增服务器」→ 填地址 + 密码/访问 Code → 点「保存设置」；
3. 下拉框选中要推送的那台（★ 为当前目标，切换立即生效）；
4. 点右上角「⚡ 立即推送 code 到选中服务器」，或等插件按「自动推送间隔」定时推送；
5. 删除服务器：选中后点「删除该服务器」→「保存设置」。

Windows 独立运行（不开萌卡时调试用）
------------------------------------
解压后双击 start-win.bat，会用包内 node-win-x64.exe 启动独立管理页：
     http://127.0.0.1:8088
可在「服务器管理」里配置服务器并查看页面，但独立模式没有萌卡框架，
无法取码（点推送会提示未连接框架）；它的用途是验证包能跑、Windows 防火墙/端口是否正常。
端口可用环境变量改：set QQFARM_ADMIN_PORT=8099 后再运行。

三种农场后台自动适配
--------------------
* 「访问 Code」版：自动探测 /api/auth/status，用密码字段作为访问 Code 登录（会话走 Cookie）；
* 账号密码版：POST /api/login {username,password} 换令牌；
* 无登录验证版：/api/login 不存在时直接推送，不带令牌。
令牌失效（401）会自动重新登录重试一次。

注意
----
* 农场面板里的账号备注需与 QQ 号完全一致，否则会新增账号而不是重新登录取代；
* get_qq_farm_code 仅 Android QQ 支持，Linux QQ 取码会失败（页面会标注），默认关闭；
* 服务器列表保存在插件数据目录 servers.json，升级插件不会丢；
* 萌卡不支持同版本重装、也不允许降级，重新上传前必须提高版本号；
* Windows 上如果萌卡是服务方式运行，请确认它有权限执行插件目录里的 bin\node-win-x64.exe
  （一般导入时框架会自行设置；被安全软件拦截时把插件目录加入白名单）。
